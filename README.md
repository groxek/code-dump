# code-dump

Свалка моего кода: учебные скрипты, алгоритмы и первые пет-проекты. Хроника развития.

## Структура репозитория

* `/csharp` — текущий мейн-стек. Песочница для изучения синтаксиса и базовых концепций.
* `/frontend` — эксперименты с версткой (HTML, Bootstrap).
* `/go` — замороженная практика (структуры, базовые тулы).
* `/python` — архив со старыми скриптами и алгоритмами.
