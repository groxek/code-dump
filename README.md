# code-dump

Свалка моего кода: учебные скрипты, алгоритмы и первые пет-проекты. 
По сути, это хроника моего развития в бэкенде перед стартом учебы в Универе.

## Структура папок

* `/leetcode` — практика алгоритмов и структур данных.
* `/projects` — здесь пилю свои пет-проекты, ковыряю FastAPI и собираю REST API.
* `/sql_learning` — запросы и практика по базам данных.
* `/sandbox` — песочница со всяким рандомом: тесты, черновики по ООП и одноразовые скрипты.

По мере готовности буду выносить нормальные проекты из `/projects` в отдельные полноценные репозитории.
